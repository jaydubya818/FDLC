## Selected developments

| Published | Development | Evidence and limits |
| --- | --- | --- |
| Nov 27 | Tessl CLI 0.126.0 connects each requested Loop run to the execution it started. | The versioned changelog distinguishes a request, its admission status and the resulting launch. A lost acknowledgement can leave the caller uncertain even when a job started. Operators can resolve that uncertainty through run history. [Tessl release notes](https://docs.tessl.io/changelog-cli#01260) |
| Nov 27 | GitHub Copilot CLI added explicit tool selection for custom agents. | GitHub published 1.0.117 as a stable release at 13:04 UTC. Its notes also cover consistent use of the declared tools when delegating work. This concerns the authority of each worker, distinct from the earlier Copilot review billing entry. [GitHub release](https://github.com/github/copilot-cli/releases/tag/v1.0.117) |
| Nov 25 | Goel, Steenhoek and Hu measured how removing one edit affected a successful agent patch. | Their 7,660 runs covered SWE-bench Verified and DeepSWE. The roughly 11% finding applies to code blocks on SWE-bench Verified. The authors explain that tests can miss wanted behavior and that changing one block at a time can miss dependencies between edits. [Versioned preprint](https://arxiv.org/abs/2611.34875v1) · [Method and limitations](https://arxiv.org/html/2611.34875v1) |
| Nov 25 | Asgari and colleagues compared ways to choose a smaller set of evaluation tasks. | Their study covers ten benchmarks. The 100-task example and its 0.8 percentage-point estimation error apply to one agent on SWE-bench Verified. A sample deliberately selected to expose failures serves a different purpose from one used to estimate the pass rate. [Versioned preprint](https://arxiv.org/abs/2611.34617v1) · [Experimental results](https://arxiv.org/html/2611.34617v1) |
| Nov 24 | Steve Yegge described how his factory carries a role’s history across sessions. | The interview and transcript identify what the next worker inherits. We label this a perspective. The interview gives no controlled measurement of token savings. The entry uses the interview’s publication date. [Software Engineering Daily](https://softwareengineeringdaily.com/podcasts/steve-yegge-on-building-software-factories/) · [Original transcript, around minute 16](https://softwareengineeringdaily.com/wp-content/uploads/2026/11/SED1980-Steve-Yegge-2026.txt) |
