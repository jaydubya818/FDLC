| Nov 26 | KiroBench compares evaluation coverage with the jobs developers bring to Kiro. | The team describes more than 300 private tasks, including tasks derived from volunteered sessions. | Nov 25 | Vercel Workflow SDK 5.8 introduced speculative execution of retryable steps. | Vercel documents how a stable step ID prevents duplicate external writes when the destination supports idempotency. Setting retries to zero opts a step out. These execution semantics are separate from the November 24 data-retention change. [Vercel release notes](https://vercel.com/changelog/workflows-speculative-execution) |
| Nov 25 | GitHub announced a change to the default payer for Copilot code reviews. | December 30 is the effective date. The change applies to eligible Business and Enterprise accounts without a saved billing choice. GitHub lists exceptions and explains how to keep member billing. [GitHub announcement](https://github.blog/changelog/2026-11-25-copilot-code-review-billing-will-default-to-the-organization/) |
| Nov 24 | SpecEngineeringBench measured how often an agent-written test distinguished defective code from its repair. | The mean fail-to-pass rate across seven agents was 26.36%. The paper averages test fractions within instances for that metric. Its 91.47% mean head-pass rate answers a different question about compatibility with repaired code. We use the first arXiv submission date. Yesterday’s SWE-bench study examined whether grading tests followed the written requirements. [Versioned preprint](https://arxiv.org/abs/2611.32973v1) · [Metric definitions and results](https://arxiv.org/pdf/2611.32973v1) |
| Nov 23 | Claude Ship introduced separate beta roles for maintaining a pull request and evaluating a team’s approval policy. | Anthropic lists GitHub repositories on Team and Enterprise plans. Review was already generally available. An approval policy can operate in observe mode, and the repository’s branch rules govern merges. This was a late discovery in the overlap window. [Anthropic announcement](https://claude.com/resources/articles/introducing-claude-ship) |
